# App settings

Media ExplorerのSoundPrepバーにある **Settings…** から開く。狭い表示では **Edit → App settings…** からも開ける。

macOSではCocoa、WindowsではWin32のネイティブ設定パネルを使用する。外側をクリックしても閉じず、Media Explorerやプロジェクトと行き来できる。**Done**、タイトルバーの閉じるボタン、またはEscapeで閉じる。Settingsをもう一度押すと、同じパネルが手前に出る。SoundPrepの終了やMedia Explorerへの接続解除時はパネルも片付ける。

| タブ | 内容 |
| --- | --- |
| Playback | ファイル選択に追従して再生、ループ、モニター音量、試聴の端のフェード |
| Drops | 未キャッシュ素材の自動レンダー、選択範囲外の音声保持、レンダー音声のフェード、選択したドロップのレンダー |
| Cache | 解析キャッシュの場所。キャッシュ保存先の変更に対応するアプリでは、フォルダー選択と既定に戻す操作も利用できる |
| Advanced | 非アクティブFXの処理継続、動作カウンター |

設定は全プリセットで共有し、自動保存する。プリセットのSaveとは独立している。モニター音量は試聴に即時反映し、書き出し音声には含めない。スライダー操作中は保存をまとめ、操作完了またはパネルを閉じる際に確定する。数値欄への直接入力も可能で、範囲外や不正な入力は適用しない。

操作バーの **Monitor -6.0 dB** も同じモニター音量を変更する。隣の **Norm -18.0 LUFS** は素材のNormalize目標値で、試聴とD&Dに反映する。Zwickerを選択したプリセットでは **Norm 36.00 sones** のように表示し、メニューからPreset編集で目標を変更する。

別プロジェクトに切り替えるとパネルを残したまま変更操作を無効にする。元のプロジェクトへ戻ると操作できる。閉じる操作は常に利用できる。

PresetとToolsも[ネイティブ編集パネル](preset-tools.md)を使用する。Native helperを更新する場合はREAPERを終了してから入れ替え、再起動する。

## 開発時の確認

- `lua tests/run.lua`: 保存、即時反映、保存失敗時の復元、不正値、プロジェクト切り替え、閉じる際の確定。
- `native/test_bar.mm`: Cocoaの実コントロール、パネル維持・再表示・終了、数値入力、Unicodeパス、レイアウト。
- `native/windows/test_windows.cpp`: Win32の実コントロール、非アクティブ化後の維持、編集値の保持、REAPERショートカットとの分離、終了時の破棄。
- `tests/native-bar-cases.json`: 両OSで共通の状態検証。

Windowsの実REAPERでは表示倍率の変更、Tab/Shift+Tab、数値欄のEnter、フォルダーダイアログからの復帰、別プロジェクトへの切り替えも確認する。
