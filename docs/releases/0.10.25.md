# Audition Macro 0.10.25

The first public distribution of Audition Macro, a Media Explorer companion for REAPER.

- Audition files through persistent FX presets, with Reverse, Pitch, Rate and Raw/Macro comparison.
- Normalize preview and drag-and-drop audio, including 3–128-channel sources. Completed analysis adjusts an active preview gradually without Replay.
- Keep the original channel count or select stereo downmix. Original-channel multichannel preview bypasses Macro FX while retaining transforms and common gain.
- Use a simple W/Y M/S stereo preview for ACN/SN3D AmbiX material. This is not a full spatial decoder.
- Drag audio into Arrange with editable Source + FX and Rendered takes. Odd channel counts are preserved.
- Install the scripts, actions and matching native helper together through ReaPack, or use an OS-specific ZIP.

Requires REAPER 7.35+, SWS, JS_ReaScriptAPI and ReaImGui. Normalize and source peak guard additionally require Python 3.10+ and FFmpeg/ffprobe. Save your work and restart REAPER after installing or updating the native helper.

macOS packages contain an Apple Silicon/Intel universal helper. Windows packages target Windows 10/11 with REAPER x64. The latest multichannel and automatic Normalize flows have been tested in real REAPER on macOS; Windows builds and automated tests do not establish complete mouse, IME or audio-device coverage.
