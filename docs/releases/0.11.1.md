# SoundPrep 0.11.1

This release removes dictionary-based Search Assist and corrects the multichannel documentation and third-party attribution. Both the scripts and native helper must be updated. Save your work and restart REAPER after updating through ReaPack or the OS-specific ZIP.

- Remove Search Assist from the control bar, preset editor and registered Actions. Dictionary data and its research documents are excluded from the new runtime packages and current public source. Media Explorer's native search remains available. Existing user settings and dictionary files are not deleted; obsolete search shortcuts no longer change the search field.
- Document **1st through 10th order AmbiX input (ACN/SN3D, 4–121 channels)**. Stereo audition uses only W/Y; it does not decode higher-order, height or front/back spatial information.
- Clarify that **Macro FX process the stereo downmix of multichannel sources**. Downmix OFF retains the source channels and bypasses Macro FX. Reverse, Pitch, Rate and common gain remain available.
- Retain upstream MIT notices and add the missing UTF-8 decoder, Grisu2 and Hedley copyright notices embedded in nlohmann/json. Include the original Apache-2.0 license and attribution for its Abseil-derived source. Keep MoSQITo-derived code under Apache-2.0 and libebur128-derived code under MIT.
- Check native feature revisions as well as the version, format and SHA-256 when preparing prebuilt helpers and packages. A helper with the obsolete Search UI is rejected even if its version string matches.

The source and binary publication policy is unchanged: the analysis implementation is distributed inside the helper, while the approved Lua and Native integration sources remain public. See the [license audit](https://github.com/PontakuAudio/SoundPrep/blob/v0.11.1/docs/license-audit-2026-10-22.md) and [installation guide](https://github.com/PontakuAudio/SoundPrep/blob/v0.11.1/docs/install.md).

ReaPack repository URL remains:

```text
https://github.com/PontakuAudio/SoundPrep/releases/latest/download/index.xml
```

Manual-install packages are `soundprep-0.11.1-macos-universal.zip` and `soundprep-0.11.1-windows-x64.zip`. Preserve the existing `data/` directory when updating. Earlier releases and their assets remain unchanged.
