# SoundPrep 0.11.2

This documentation update includes the corrected README, third-party attribution and license audit in the ReaPack package and both OS-specific ZIPs. Third-party copyright notices and license texts are retained.

The package uses the verified native helper 0.11.1 for macOS and Windows. Audio processing and controls are unchanged. When updating from 0.11.0 or earlier, update the helper and restart REAPER as described in the [installation guide](https://github.com/PontakuAudio/SoundPrep/blob/v0.11.2/docs/install.md).

Synchronize ReaPack and update SoundPrep to 0.11.2, or download `soundprep-0.11.2-macos-universal.zip` / `soundprep-0.11.2-windows-x64.zip`. Preserve the existing `data/` directory when updating from a ZIP.

ReaPack repository URL:

```text
https://github.com/PontakuAudio/SoundPrep/releases/latest/download/index.xml
```

See the bundled [license audit](https://github.com/PontakuAudio/SoundPrep/blob/v0.11.2/docs/license-audit-2026-10-22.md) for the retained third-party attribution.
