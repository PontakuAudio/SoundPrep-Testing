# SoundPrep 0.11.4 — Audition waveform selections

Fixes waveform selections being ignored for playback when REAPER reports a loop selection. SoundPrep now recognizes both loop and time selections, starts auditioning from the selected range when stopped or playing, and uses the same bounds for waveform seeking, selected-channel highlighting and selection zoom.

Waveform drags also temporarily remove SoundPrep's playhead and selected-channel overlays so REAPER can draw its native selection feedback. Overlays resume after release or cancellation without reopening the source or rebuilding cached peaks.

Regression coverage includes the reported selection flags, stopped and playing audition gestures, native seek coordinates and overlay/zoom bounds. The Windows comparison probe checks actual mouse drags and playback from the resulting range against the published 0.11.3 package.

Update SoundPrep through ReaPack, then save your work and fully restart REAPER to load the bundled 0.11.4 helper. The ReaPack repository URL is unchanged.
