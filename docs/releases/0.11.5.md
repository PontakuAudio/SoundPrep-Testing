# SoundPrep 0.11.5 — Readable waveform microphone names on Windows

Fixes waveform microphone names appearing extremely small on Windows. Labels now use a 13-pixel character height at 100% desktop scaling and follow the waveform window's display DPI, including fractional scaling. Font sizing no longer includes internal leading in the requested glyph height.

Label backgrounds, padding and available lane height scale with the text. Moving between monitors refreshes the font and label layout without re-reading waveform peaks when the waveform dimensions are unchanged. macOS keeps its existing text sizing.

Update through ReaPack, save your work and fully restart REAPER to load helper 0.11.5. The repository URL is unchanged.
