# SoundPrep 0.11.6 — Smooth microphone labels on Windows

Windows waveform labels now use DirectWrite to shape the complete Unicode string and render smooth grayscale text. This replaces the per-character GDI bitmap cache, improving small glyph contours, Japanese text and spacing. Text is drawn at twice the final resolution and area-averaged to smooth the edges. Grayscale rendering avoids colored fringes when a waveform selection tints the text.

The DPI-aware text size from 0.11.5 is retained. Long names are trimmed with an ellipsis, and rendered labels are cached with an 8 MiB / 128-entry limit so playhead movement does not repeatedly shape text. macOS continues to use Cocoa text rendering.

Update through ReaPack, save your work and fully restart REAPER to load helper 0.11.6. The repository URL is unchanged.
