# SoundPrep 0.11.7 — Clear startup and ReaPack update date

ReaPack now displays Last Update for this release. The release index records the source commit's UTC timestamp; rerunning the same commit keeps that timestamp stable. Earlier release entries and downloads are preserved.

New installations register only **SoundPrep.lua** in the Main Action List, instead of 26 actions. Start SoundPrep from this action and use the controls in Media Explorer. The ZIP edition also starts with SoundPrep.lua: the first run installs the bundled helper if needed and asks you to save your work and restart REAPER.

Keyboard and maintenance actions remain available through the optional **SoundPrep - Install actions.lua**. Existing action registrations and shortcuts are preserved when updating, so previously registered actions remain in the Action List.

This release includes the unchanged 0.11.6 native helper for macOS and Windows. When updating from 0.11.6, quit and restart SoundPrep; a REAPER restart is only needed when installing or replacing the native helper. The ReaPack repository URL is unchanged.
